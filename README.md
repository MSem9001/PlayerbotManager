This is a fork from v1.4.

I added some buttons to the Playerbots gui window for pve specific talents.  They will summon the bot, change spec, strategy, and autogear them.

Second I added a pruning button to the Playerbots gui window to remove bots from the tracker that don't exist, and also updated the Remove Orphaned Bots to not only remove bots not in your group/raid, but also take them out of the tracker.  To make this more robust, bots are immediately added to the tracker when summoned, so they can be whispered to, to be removed.
